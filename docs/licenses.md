# Dependency License Policy

Core linked dependencies must permit proprietary commercial redistribution, normally Apache-2.0, MIT, BSD, or PostgreSQL licenses. Copyleft observability or security services may only be optional network sidecars after documented review.

Initial reviewed choices: PostgreSQL, pgvector, FastAPI, SQLAlchemy, React, Vite, React Flow, Phosphor Icons, Docling, Ollama-compatible APIs, and Qwen3 model artifacts. Before release, generate an SBOM and verify every transitive package and model license from its pinned artifact.
